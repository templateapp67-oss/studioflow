# Nexora customer app campaign

Install/open route: `/?app=1&install=1`. Existing app route `/?app=1` and all salons stay on the same origin and Supabase. No Play Store listing or APK distribution is claimed. Customers open in Android Chrome, use the native Install prompt or Chrome menu → Add to Home screen → Install. Browser availability and prompts depend on the device/browser.

All 14 public salon templates contain a compact announcement after their quick-action dock, a full app-promotion section before the footer, and an install link in the mobile drawer. The legacy owner editor includes the full promotion. Customer Home includes an app-install notice and the dedicated guide displays the poster, actual install control and steps. Owner Workspace → Marketing offers the shareable campaign.

The campaign offers Open Customer App, Install guide, Share App & Poster, Copy app link and Download ad image. Native share includes the PNG when supported; otherwise it shares the app link. Clipboard fallback copies Hindi/Hinglish message and the complete install route. No external broadcasts/messages are sent automatically.

Project asset: public/promo/nexora-customer-app-ad.png. Original generated image preserved. Built-in image_gen used; final prompt: ads-marketing, portrait 4:5 promotional poster for Nexora Indian customer salon booking app, premium purple/violet/warm white with lime accents, smartphone salon-search/services/slots mockup and salon styling photography. Exact principal copy: “अब salon booking, सीधे app से!”, “Salon खोजें • Services चुनें • Slot बुक करें”, “हर बार website खोलने की ज़रूरत नहीं”, “Android Chrome में खोलें और Install करें”, “एक app में अपने salon खोजें और bookings संभालें”. No QR code, app-store logos, ratings, invented payment success, discounts or rewards.

Validation: all-14-template campaign presence/links/poster-download regression, existing complete website wiring suite, customer profile regression, native-share/clipboard/cancellation tests, TypeScript, production build and PWA checks.
