It also reads the JPEG frame dimensions for all eight marketing-route social cards and compares them to their declared OG sizes; template cards do not declare sizes. Empty alt is allowed for decorative images. The seven empty alts on growth rewards are decorative hero medallions; their reward cards have meaningful alternatives. The privacy notice deliberately has no JSON-LD; structured data is optional.
- Existing suites separately exercise public routing/SEO, breadcrumbs, published salon SSR, link integrity, demo-lead server and client response contracts, and the Jaipur competition/directory. The static test does not prove client hydration, full schema eligibility, external link availability, dynamic salon/listing contents or deployed HTTP behavior.
