# Pink/white customer app and wellness categories

Reference images reviewed: image(20261016-053116).png and image(20261016-053847).png. Applied their compact, photo-first discovery pattern using Nexora's own content: white/soft-pink surfaces, magenta actions, circular category images, compact horizontally scrolling service cards, obvious search and the existing five-image automatic header. Service descriptions and guidance remain available in expandable details. The full template catalogue is retained under Browse all.

Six main category tiles: Hair Salon, Barber Shop, Beauty Parlour, Spa, Massage and Tattoo Studio. Groups cover all 14 existing template IDs, including unisex, hair colouring, bridal/makeup, skincare, nails/lashes, hair spa and Ayurvedic spa. Filtering uses actual published salons, and shows truthful availability/counts. Category names also participate in keyword search so searching spa finds Ayurvedic spa salons even if their names don't contain spa. No sample shop is presented as bookable.

Reference-only claims such as a free haircut, guaranteed 30-minute arrival or at-home services are not invented; real published salon offers and services remain connected to the shared catalogue. Booking summary, advance, QR/checkout, ₹0 demo, owner delivery, reviews, saved salons, profile photographs, loyalty, referral and install/share features are retained.

Validation: all-category mapping and interaction regression, category keyword search, existing complete customer booking/reference/carousel/profile regressions, TypeScript, production build and PWA checks. Physical Android device unavailable.

Live Chrome visual review: pink/white header, five-slide banner, all six photo categories and compact service layout rendered. Clicking Beauty Parlour showed the truthful no-published-salons message; clicking Spa showed Best Salon and its five current services. Physical Android viewport/device was not available.
