# Customer ZIP UI integration

Design source: user-provided costomer-app--main.zip (October 16, 2026).

The customer app retains the existing StudioFlow Supabase project, RPCs,
private profile storage, account RLS, published templates, public map cache,
25% advance payments, webhook verification and isolated zero-rupee demo flow.
No schema, owner records, live appointments or payment settings are replaced.

The reference's lavender/white surfaces, violet actions, branded navigation,
directory search, recommendation cards, categories, reels, salon cards,
Explore filters, appointment cards, loyalty and profile panels are applied
to the real customer views. Existing extra categories and installation entry
points remain available. Responsive layout uses the reference 1024px maximum.

The reference's hard-coded customer, bookings, ratings, availability,
vouchers, cash rewards, local payment-success simulator and database debug
panels are excluded. Business values come from the existing catalogue and
account APIs. Empty states are explicit where a real salon has no data.
