# Bodhi Tree (Template 09) — Local Asset Manifest & License Credits

All visual assets for **Bodhi Tree Massage & Wellness Sanctuary (`massage_wellness` / Template 09)** are stored locally under `/public/templates/bodhi-tree/` with zero external hotlinks.
Owners can replace any slot via the Onboarding Wizard or Admin Website Editor (stored in Supabase Storage bucket `studioflow-media`); when a custom upload is removed or unavailable, the storefront falls back cleanly to these local WebP/SVG/PNG/JPG assets.

## License Summary

- **Pexels / Unsplash free-license photography:** Free for commercial and non-commercial use, modification permitted, no attribution required (Pexels License / Unsplash License). Every photo was resized/cropped and re-encoded to WebP (each ≤ ~170 KB) for fast loading.
- **AI-generated placeholders (hero, Shirodhara, Rambagh garden, two therapist portraits):** Synthetic imagery created for StudioFlow where no suitably licensed free photograph was available. No real private individuals; royalty-free for commercial & SaaS template distribution.
- **Vector logo & favicons (`logo.svg`, `favicon.svg`, PNG derivatives):** Original peepal (bodhi) leaf artwork authored for StudioFlow.
- All treatment imagery is professional and towel-covered. No identifiable celebrities.

## How the site uses these

- `hero.webp` (desktop) + `hero-mobile.webp` (phones) render with a deep forest-green overlay so cream text stays readable (WCAG AA).
- `palace/*.webp` are portrait 3:4 for the jharokha (arch) frames of the Jaipur Palace Collection.
- Images below the fold are lazy-loaded (`loading="lazy"`) with fixed width/height to avoid layout shift; the hero loads eagerly.
