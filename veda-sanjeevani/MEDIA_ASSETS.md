# Generated media in the website

Three AI-generated, illustrative still images have been created and integrated. They contain no identifiable people, text, logos, medical claims, or testimonials.

| Source | Responsive output names | Used for |
| --- | --- | --- |
| `assets/source/ayurvedic-spa-hero.webp` | `public/images/ayurvedic-spa-hero-{400,800,1600}.webp` | Homepage hero, booking background, gallery card |
| `assets/source/warm-herbal-oil-ritual.webp` | `public/images/warm-herbal-oil-ritual-{400,800,1600}.webp` | Abhyanga service card and gallery |
| `assets/source/ayurvedic-herbs-still-life.webp` | `public/images/ayurvedic-herbs-still-life-{400,800,1600}.webp` | About section, Panchakarma card and gallery |

`npm run assets` regenerates responsive WebP variants. These are illustrative images, not photographs of the actual studio, practitioners, or guests. Replace them with verified, consented studio photography before representing them as real business premises or services. The generated oil-ritual composition is intentionally framed without a face; review it before production use.

The attached prompt library includes additional image prompts for the other service slots, team, quiz, packages, gallery, testimonials and blog. Those additional images have **not** been generated in this pass. No video file was generated: the available media generator creates still images only. Video prompts can be adapted from the supplied attachment for a video-generation provider; any deployed clips should be muted, loopable, poster-backed, under the target size, disabled on mobile/reduced-motion where appropriate, and checked for consent and accessibility.
